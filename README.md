## 📡 ARCHITECTURE_OVERVIEW

### 1. The Global Header (Interface)

* **Dual-State Navigation**: Transitions from a wide top-bar to a floating bottom-dock upon scrolling (`scrolled` state logic).
* **Silver_Shimmer Animation**: Custom CSS-keyframe gradients applied to typography.
* **Smart_Index**: A mobile-first menu system that auto-closes on section navigation.

### 2. Bento Grid (Modules)

* A modular "What I Can Do" section using CSS Grid and Flexbox to create a hierarchical information flow.
* Interactive hover states that utilize `transition-all` for smooth scaling.

### 3. Smooth_Scroll_Engine

* Custom SPA logic using `scrollIntoView` to handle navigation between `#services`, `#stack`, and `#about`.
* `scroll-padding-top` implementation to prevent the fixed header from overlapping section titles.

### 4. Project_Archive

* **Scanline Effect**: A CRT-inspired overlay created with linear gradients to enhance the "Terminal" aesthetic.
* **Encrypted State**: Project modules are currently set to a "Classified" state using a centralized `LOCKED_IMAGE` constant for easy batch updates.

### ⌨️ Typography_Protocol

* **Headings**: `Inter` / `System-Sans`
* *Weight*: Black (900)
* *Tracking*: `tracking-tighter`
* *Case*: Uppercase (System Standard)


* **Data / Logs**: `JetBrains Mono` / `Fira Code`
* *Weight*: Medium/Bold
* *Tracking*: `tracking-[0.3em]` or `widest`
* *Usage*: Navigation links, tech tags, and status indicators.

* **Border_Radius**: `3xl` to `full` (Rounded-4xl for main panels).
* **Backdrop**: `blur-3xl` for high-density glassmorphism.
